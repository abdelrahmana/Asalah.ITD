# Exploring Kyoto, Japan - Web Project

A responsive HTML5 and CSS3 webpage showcasing Kyoto, Japan. This project follows clean web standards and is structured for both standalone browsers and online playgrounds like CodePen.

## Features

* **Detailed Description:** Includes over 100 words covering Kyoto's history, architecture, and scenery.
* **Viewport-Centered Image:** Utilizes CSS Flexbox to ensure the primary image remains centered regardless of screen size.
* **Responsive Gallery:** Displays supplementary images using flexible layout rules.
* **Structured Information:** Contains an unordered list (`<ul>`) of top attractions.
* **External Stylesheet:** Pure separation of structure and design with no inline CSS rules.

## Project Structure

* `index.html` — Semantic HTML structure including `<head>`, `<body>`, and `<main>`.
* `style.css` — Styling rules, Flexbox layouts, typography, and responsive media handling.
* `README.md` — Documentation.

## How to Run

1. Place `index.html` and `style.css` in the same directory.
2. Double-click `index.html` to open it in any web browser.
3. For CodePen, paste the contents of `<body>` into the HTML tab and the styles into the CSS tab.
